## 막혔던 것 / 잘못 알고 있던 것

**1. axis를 "방향"으로 외우고 있었다**
- 기존 이해: axis=0은 위에서 아래로, axis=1은 왼쪽에서 오른쪽으로
- 문제: 2차원에서만 통하고 3차원 이상에서는 설명이 안 됨
- 수정: **axis=n은 n번째 축이 결과에서 사라진다**
  - (2,3,4).sum(axis=1) → (2,4)

**2. 브로드캐스팅 규칙이 불완전했다**
- 기존 이해: 축 크기가 같거나 하나가 1이면 된다
- 문제: (2,3) + (3,)처럼 축 개수가 다른 경우를 설명 못 함
- 수정: **오른쪽 끝 축부터 맞추고, 모자라는 왼쪽 자리는 1로 채운다**
  - (3,) → (1,3)으로 채워져서 (2,3)과 성공
  - (2,3) + (2,)는 오른쪽 끝이 3 vs 2라 실패

**3. 행렬곱을 모르고 있었다**
- `*`는 원소별 곱(같은 자리끼리), `@`가 행렬곱
- shape 규칙: (a,b) @ (b,c) → (a,c). 안쪽이 같아야 하고 계산 후 사라진다
- A @ B ≠ B @ A
